Only proven, end-to-end verified steps go in the guide. Never put unverified commands in instructional content.

**Why:** Jul 7 incident — Elia spent an evening following ncl commands for Elvis setup that didn't work (restarted: 0, container config not found, etc.). He was exhausted and frustrated. "We worked unprofessionally" — he felt I let him experiment instead of researching first.

**How to apply:** Before writing any guide step, verify it works in a real environment. Research deeply first. If something is uncertain, say so explicitly and don't put it in guide-format instructions.
