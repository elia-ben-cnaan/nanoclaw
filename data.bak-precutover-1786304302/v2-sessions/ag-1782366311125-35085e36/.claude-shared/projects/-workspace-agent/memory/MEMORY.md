# Memory Index

- [No tables in Telegram](feedback_no_tables_telegram.md) — Use numbered lists/bold text, never markdown pipe tables

- [Proactive contacts](feedback_proactive_contacts.md) — When referring to support/contacts, always search and include direct links/emails in the same message
- [Explain before asking](feedback_explain_before_asking.md) — Before asking user to create accounts/connect services, explain clearly what's needed and why first
- [Recommend best + free](feedback_recommend_best_free.md) — Always recommend best quality + most free tools, with pros/cons upfront, decide together
- [Async delivery](feedback_async_delivery.md) — For long tasks (video/image gen): say upfront it'll take time, then deliver result immediately when ready — no need to be asked
- [Verify before recommending](feedback_verify_before_recommending.md) — Always test a tool/process works before recommending it; never lead user into a flow that fails midway
- [Copy buttons for text to copy](feedback_copy_buttons.md) — Use send_card with copy elements instead of inline text when user needs to copy/paste a value
- [Think before acting](feedback_think_before_acting.md) — Fully verify an approach end-to-end before guiding the user to take any action
