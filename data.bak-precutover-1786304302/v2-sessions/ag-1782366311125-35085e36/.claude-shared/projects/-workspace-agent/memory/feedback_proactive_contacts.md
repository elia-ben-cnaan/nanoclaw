When pointing the user to contact a company, service, or person, proactively search for and include the direct contact info (email, Discord invite, Twitter, etc.) in the same message. Do not just say "contact them via their website" — find the actual link/email and include it inline.

**Why:** User explicitly asked not to have to make a second request just to get the actual contact details.

**How to apply:** Whenever a response would otherwise say "contact X through their website/channels", run a quick search first and include the direct link or email in the same message.
